# Uygulama simgeleri

`postacim/ikonlar/` altındaki PNG'ler arayüz düğmeleri ve klasör simgeleri
içindir (20×20, `tk.PhotoImage` ile yüklenir).

Uygulamanın **k masaüstü simgesi** (`Icon=` alanı, paketlemede `hicolor`
temasına `postacim.png` olarak) henüz eklenmemiştir. Beklenen boyutlar:

- `48×48`, `64×64`, `128×128`, `256×256` (PNG, şeffaf zemin)

Geçici olarak sistemdeki `mail-unread` simgesi kullanılır.
